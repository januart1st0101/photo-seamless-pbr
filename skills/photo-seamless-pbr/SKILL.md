# 照片轉 4K 無縫材質貼圖

以繁體中文回覆。用一張或多張參考照片製作可用於 Cinema 4D、Redshift 等 3D 工作流程的 4096 × 4096 PNG 材質。使用者已指定尺寸時以其指定為準；本流程預設 4K。先查看原圖、材質特徵與使用者已表達的偏好，不重複詢問。

## 製作

1. 保存原照片並檢視拍攝角度、可見範圍、光線、材質顏色、花紋和板縫／磚縫；原檔不覆寫。以可用的內建 imagegen 編輯原圖，校正為正面視角，移除拍攝光影、反射和雜物，保持原始材料的顏色、紋理、比例、磚縫或木板錯縫；指定不可增加不相干結構。拿結果與原照比對；AI 推測被遮住的部分，不能宣稱色彩或細節經實測精確還原。保存正面校正圖。必要時修正；仍不忠實則告知並交付較好的可用結果。
2. 製作上下左右可重複的 Base Color；保留材質的方向、拼縫、細節，不能因簡單鏡像或寬幅混合造成可見重影、破碎板縫。人工選取對應結構再進行接邊；平鋪檢查 3×3 圖。預設每張同方向，依使用者要求改動。先把已完成無縫處理的 Base Color 使用高品質插值放大為 4096 × 4096，保存這張 4K 圖，再從它製作其他資料貼圖。所有貼圖必須與 4K Base Color 構圖、UV、比例一致，且為 4096 × 4096。若原圖或生成結果解析度不足，應明說插值不等於新增真實細節。
3. 使用放大完成的 4K、可平鋪 Base Color，生成對齊的 Normal、Roughness、AO、Specular、Height、Refraction/Transmission。可使用 `scripts/build_maps.py`：

   ```sh
   python scripts/build_maps.py '已處理BaseColor.png' '輸出資料夾' --material opaque
   ```

   腳本需要 Python、Pillow、NumPy；使用環境提供的依賴定位工具尋找可用 Python。腳本先將來源放大並儲存 4K Base Color，再從這張 4K 圖產生其他貼圖，最後將所有貼圖、3×3 預覽及技術說明打包為輸出資料夾旁的 ZIP；不處理正面校正、不自動修復接縫，接受輸入的是已製作且檢查過的平鋪 Base Color。若有既有不同版本，另建資料夾，不覆寫。對反光、折射或透明度無法自照片判斷時，勿捏造表面數據；可用估計和明確標示的中性預設。法線提供 OpenGL（Y+）和 DirectX（Y−）版本；Height 以 16-bit 灰階輸出。
4. 以檔案實際尺寸及位深檢查成果；看 Base Color 及 3×3 預覽，確認方向、邊緣與明顯重複。檢視各資料圖是否與顏色貼圖的構圖一致。若接縫未修好，修正後重做派生貼圖；無法消除時明確說明。預覽只是平鋪影像，並非材質渲染。
5. 將所有產出的 4K 材質貼圖、同方向 3×3 預覽與使用說明打包成一個 ZIP，並驗證內容與壓縮完整性。提供 ZIP 下載連結，同時直接顯示 Base Color 和拼接預覽；使用者要求時再顯示其他個別圖片。正面校正參考圖可以另外保存；不要誤稱它或 3×3 預覽為 4K 貼圖。若透明材質欠缺透光參數，打包已完成的貼圖並在說明中標明缺少的項目。尊重後續明確指定的交付方式；NODE 工作區依其 AGENTS.md 使用 `NODE工作區/02_工作中/<主題>/`，不自行發布。

## 材質與限制

- Base Color 用 sRGB；Normal、Roughness、AO、Specular Weight、Height、Transmission 作非色彩資料（Raw／Linear）。具體通道依渲染器版本，不能聲稱已在 Cinema 4D 渲染驗證，除非實際驗證過。
- Normal、Roughness、AO 與 Height 由照片外觀推估，非掃描、實測、真正的幾何或光學資料；凹凸、粗糙度與顏色的關係不能保證真實。高光 Specular 預設為全白的中性反射權重控制，不是拍攝時亮斑；粗糙度控制反射清晰度，實際高光由材質、光源與 IOR 共同決定。視渲染器，無需接入 Specular 圖，採預設 IOR／反射權重即可，避免重複調制。
- 對瓷磚、木材等不透明表面，Refraction/Transmission 是全黑（透光量 0），不是 IOR 圖；不透明物體同樣可能有表面反射。IOR 為材質數值，不能由單張照片可靠推算；沒有依據不製造「實測 IOR 圖」。透光材質須先取得可信材質參數或使用者的明確設定，再使用 `--material transparent --transmission <0至1>` 產生明確標示為使用者設定的均勻透光圖；無足夠資訊時先交付其餘貼圖並說明需提供透光度。不得將黑色預設誤稱透明材質的實際折射。
- 避免把 AO 硬烘焙到 Base Color；AO 是否連接取決於渲染器與需求。資料圖的黑白方向和推估限制應在交付時說明。重複拼貼有週期，即使四邊可接合仍可能有視覺規律。
